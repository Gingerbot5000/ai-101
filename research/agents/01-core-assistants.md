## ChatGPT (OpenAI)

### Key Updates
- **GPT-5.2/5.3 models** now available; free tier gets up to 10 GPT-5.2 messages per 5-hour window, then falls back to mini model ([OpenAI Help Center](https://help.openai.com/en/articles/11909943-gpt-51-in-chatgpt))
- **Interactive Learning Modules** — real-time formula and variable manipulation across 70+ math/science topics (Pythagorean theorem, ideal gas law, etc.)
- **Expanded Memory** — auto-organizes saved preferences by relevance; no repetition needed
- **Shared Projects** — multi-user collaboration across Free, Plus, Pro, and new "Go" plan (web + mobile)
- **ChatGPT Go plan** — new mid-tier; 10× more messages than free + image creation + file uploads
- **Ads on Free tier** rolling out in select countries to fund expanded free access ([OpenAI Help](https://help.openai.com/en/articles/9275245-chatgpt-free-tier-faq))

### Beginner Value
- Free tier still functional for casual use (text, limited image gen, GPT Store)
- Interactive science/math modules = strong for students
- Memory eliminates "re-explain yourself" friction

### Caveats
- Free tier message cap is real and disruptive during peak hours
- Advanced features (data analysis, DALL-E, file uploads) rate-limited more aggressively on free
- Ads on free tier may affect trust perception for some audiences

### Slide-Safe Claims
> "ChatGPT's free tier now includes access to GPT-5.2 with a per-session limit, interactive science learning tools, and persistent memory — making it a capable starting point for everyday tasks."

## Claude (Anthropic)

### Key Updates
- **Claude Sonnet 4.6** is default model for both Free and Pro as of early 2026 — 1M token context window ([Anthropic](https://www.anthropic.com/news/claude-sonnet-4-6))
- **Dynamic Chart & Visualization generation** — inline charts with sliders, buttons, animations; released ~March 13, 2026 ([The Register, March 13 2026](https://www.theregister.com/2026/03/13/claude_charts_a_new_course/))
- **Claude Cowork** (Jan 2026 research preview) — GUI-based coding assistant aimed at non-technical users
- **Free tier now includes** file creation, skills, and conversation compaction
- **Claude Opus 4.6** — 128k output tokens, extended thinking, up to 1M context; paid/API tier

### Beginner Value
- Strongest long-document reading of the three (1M context on free)
- New chart generation removes need for separate tools (Excel, Sheets) for basic data viz
- Claude Cowork opens technical tasks to non-coders
- Known for clear, nuanced writing — good for drafts, emails, summaries

### Caveats
- Free tier usage is rate-limited (Pro = 5× more usage during peak)
- Cowork is still "research preview" — not production-ready
- Less ecosystem integration than Gemini (no Google Workspace native tie-in)

### Slide-Safe Claims
> "Claude's free tier runs on Sonnet 4.6 with a 1M-token context window and now generates interactive charts inline — making it especially strong for reading long documents and producing data visuals."

## Gemini (Google)

### Key Updates
- **Google Workspace deep integration** (March 2026) — "Help me create" in Docs pulls from Drive, Gmail, Chat to generate first drafts; "Match writing style" unifies tone across docs ([Google Blog, March 2026](https://blog.google/products-and-platforms/products/workspace/gemini-workspace-updates-march-2026/))
- **Google Photos integration** — search library by people/moments; "Photos Remix" applies art styles; cinematic slideshow generation
- **Video generation** — native 9:16, up to 4K with upscaling; image editing via circle/draw/type gestures
- **65+ language support** (expanded in 2026)
- **SAT practice tests** — full-length on-demand practice inside Gemini, grounded in Princeton Review content
- **Google TV integration** — conversational TV control ("dim the screen," "adjust dialogue volume") ([TechCrunch, Jan 2026](https://techcrunch.com/2026/01/05/google-previews-new-gemini-features-for-tv-at-ces-2026/))
- Plans: Free / AI Pro / AI Ultra — features gated accordingly ([9to5Google, Feb 2026](https://9to5google.com/2026/02/21/google-ai-pro-ultra-features/))

### Beginner Value
- Best choice for anyone already in Google Workspace (Docs, Sheets, Slides, Drive, Gmail)
- Largest ecosystem reach — Android, TV, Photos, Search
- SAT/education features directly useful for students with no setup required
- Multimodal editing (draw on images) is intuitive for non-technical users

### Caveats
- Best features (4K video, Photos Remix, Workspace Docs) require Pro or Ultra subscription
- New Workspace features launched in English only / U.S. first for some features
- Less privacy-forward reputation than Claude for sensitive documents

### Slide-Safe Claims
> "Gemini is deepest inside Google's ecosystem — it can draft documents from your Gmail/Drive, edit photos with gestures, and run SAT practice tests — making it the strongest choice for students already using Google tools."
