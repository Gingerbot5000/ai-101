# Fallback Pack Manifest

Use this folder to store pre-captured outputs for live demo recovery.

## Required Assets
- `fallback-gemini-site-v1.png` (or `.mp4`): website generation result
- `fallback-creative-pipeline-v1-a.png`: image direction output
- `fallback-creative-pipeline-v1-b.mp4`: animation/storyboard output
- `fallback-notebooklm-transform-v1-audio.png`: audio overview evidence
- `fallback-notebooklm-transform-v1-map.png`: mind map evidence
- `fallback-notebooklm-transform-v1-slides.png`: slide outline evidence
- `fallback-utility-sprint-v1-job.png`: job seeker scenario output
- `fallback-utility-sprint-v1-budget.png`: budget scenario output
- `fallback-utility-sprint-v1-fun.png`: build-for-fun scenario output

## Operator Rule
If a live demo stalls longer than 8 seconds, switch to the matching fallback file immediately and continue narration.
